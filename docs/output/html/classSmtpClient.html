Подробное описание

Класс SMTP-клиента для отправки email-писем

Предоставляет статические методы для отправки писем через SMTP-сервер Gmail (smtp.gmail.com:465) с использованием SSL-шифрования. Учётные данныечитываются из файла email.txt.
