Подробное описание

Виджет восстановления пароля через email.

Пошаговый виджет сброса пароля: ввод email → проверка OTP-кода → установка нового пароля. Поддерживает блокировку при превышении лимита попыток ввода кода.

Полный сброс состояния виджета

Сбрасывает флаги ожидания, останавливает таймер блокировки, очищает все поля и возвращает виджет на шаг ввода email. Вызывается перед каждым открытием экрана сброса пароля.
