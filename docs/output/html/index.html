f(x) = { x² + 1, при x < -2

Архитектура

Приложение состоит из двух независимых компонент:

  • Сервер — TCP-сервер на порту 33333, SQLite база данных, отправка email через Gmail SMTP (SSL, порт 465).
  • Клиент — GUI-приложение на Qt Widgets с авторизацией, регистрацией, 2FA, сбросом пароля, построением графика.

Клиент и сервер общаются по TCP текстовым протоколом с разделителем ||.
